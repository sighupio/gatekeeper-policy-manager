# GPM v1.1.2

Welcome to the release of Gatekeeper Policy Manager version 1.1.2 🎉

This is a patch release including dependencies updates and new features:

- [[#1454]](https://github.com/sighupio/gatekeeper-policy-manager/pull/1454) Add the `GPM_SKIP_TLS_VERIFY` option to skip TLS verifications while connecting to the Kubernetes API Server. Thanks @daniel-maganto
- [[#1464]](https://github.com/sighupio/gatekeeper-policy-manager/pull/1463) Support building custom Docker images for running GPM in a subpath. Thanks @brisolt
